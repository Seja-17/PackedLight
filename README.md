# PackedLight

PackedLight is an AI-powered travel planning and community platform.

## Features

- Country Explorer
- AI Smart Itinerary Planner
- Travel Community
- Travel Blogs
- Budget Tracker
- AI Travel Assistant
- Travel Journal
- Favorites and Bookmarks

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS

Backend:
- FastAPI
- SQLAlchemy

Database:
- PostgreSQL

AI:
- Google Gemini API

Maps:
- Leaflet + OpenStreetMap

## Architecture

React Frontend
      ↓
FastAPI REST API
      ↓
PostgreSQL

FastAPI also connects to:
- Gemini API
- External travel APIs
